> 时间：2026-02-18 10:09（北京时间）

## 任务描述
为无级倍速功能新增“进度条上方重置按钮”，点击后可直接恢复到 1.0x 倍速。

## 执行步骤
1. 阅读无级倍速相关脚本与样式，确认当前仅支持双击标题重置。
2. 在无级倍速弹层中新增“重置”按钮并补充样式。
3. 抽取统一重置逻辑，复用到“重置按钮点击”和“标题双击”两个入口。
4. 更新 README 的功能说明，补充一键重置能力。

## 修改的文件
- `scripts/stepless-video-rate.js` - 新增重置按钮 DOM、统一重置函数、按钮点击重置事件。
- `css/stepless-video-rate-btn.css` - 新增重置按钮样式与悬停态样式。
- `README.md` - 更新 Roadmap，补充一键重置 1.0x 功能说明。

## 测试验证
- 手动验证建议：
  1. 打开 B 站任意视频，将无级倍速调整为非 1.0。
  2. 打开无级倍速面板，点击进度条上方“重置”按钮。
  3. 确认播放器速度、输入框数值、滑块位置均恢复到 1.0x。
  4. 双击“无级倍速”标题，确认仍可重置到 1.0x。
