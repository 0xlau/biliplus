# 优化倍速滑条

> 时间：2026-02-08 13:34（北京时间）
> 分支：feature/issue-172-stepless-speed-input

## 任务描述
“无级倍速”调速滑条偏短，拖动时很难精确落在目标倍速（0.1 的步进也更难控）。本次将滑条加长，并同步调整 JS 侧的拖动像素换算逻辑，确保视觉和交互一致。

## 执行步骤
1. 定位无级倍速的 UI/交互实现（`scripts/stepless-video-rate.js` + `css/stepless-video-rate-btn.css`）。
2. 增加滑条高度（box 和 progress）。
3. 抽离并统一“倍速 ↔ 滑条位置”的换算函数，去掉散落的魔法数字（88 / 17.6）。
4. 本地做 JS 语法检查与打包验证。

## 修改的文件
- `css/stepless-video-rate-btn.css` - 增加弹出框高度与滑条高度（2026-02-08 注释）。
- `scripts/stepless-video-rate.js` - 用常量+换算函数替代硬编码像素范围，拖动边界随滑条加长同步更新（2026-02-08 注释）。
